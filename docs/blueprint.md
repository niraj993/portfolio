# **App Name**: Devfolio Pro

## Core Features:

- Skills Showcase: Display a clear and concise summary of your skills (Python, MySQL, AWS, DevOps tools) using visually appealing charts or lists.
- Project Portfolio: Present your projects with descriptions, tech stacks, and links to GitHub or live demos.
- Contact Information: Include a contact form or links to your LinkedIn, email, and other relevant profiles.

## Style Guidelines:

- Primary color: Dark blue (#24292F) for a professional look.
- Secondary color: Light gray (#F6F8FA) for backgrounds and subtle contrasts.
- Accent: Teal (#26A69A) for interactive elements and highlights.
- Clean and modern layout with clear sections for skills, projects, and contact information.
- Responsive design that adapts seamlessly to different screen sizes.
- Use a consistent set of icons to represent your skills and technologies.
- Subtle animations and transitions to enhance user experience.
